# Power BI Sales Analysis Dashboard

## Project Overview
This project analyzes sales data using Microsoft Power BI to understand business performance across revenue, orders, product categories, and profitability.

## Objectives
- Analyze overall revenue and order performance.
- Identify high-performing product categories and regions.
- Evaluate profitability and sales trends.
- Develop interactive visualizations to support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling

## Key Metrics
- Total Revenue
- Order Count
- Average Order Value
- Profitability
- Regional Sales Performance

## Skills Demonstrated
Data Cleaning | Data Modeling | DAX | Data Visualization | Business Analysis

## Project Status
Dashboard development and analysis are in progress. Key findings and dashboard screenshots will be added as the project develops.
